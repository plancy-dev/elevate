## 1. 범위 문장 (한 줄)

**단기 북극성:** 유튜브 쇼츠를 **끝까지 자동 생성·업로드**할 수 있는 파이프라인을 목표로 하되, **먼저** 조직 단위 **원장(에피소드·아티팩트) + 외부 링크 + API 키(자가 보유) 관리**를 제품의 안정적인 층으로 완성한다.

**운영 전제:** 초기 타깃은 **본인/팀(1조직)**; 조직은 **자체 API 키를 연동**하고, 장기적으로 OAuth·기타 확장 여지를 설계에 남긴다.

## 2. 우선순위 스택 (아래가 위를 지지)

| 순위 | 내용 | 비고 |
|------|------|------|
| **P0** | **원장 + 링크 + 키 관리** — 에피소드/아티팩트, Integrations(암호화 저장·표시·검증), 배포 채널 URL | 이미 방향 일치; 품질·문서·역할 합의 지속 |
| **P1** | **LLM 확장 — Anthropic(Claude)** OpenAI 다음 필수 | `provider` 마이그레이션·어댑터·탭·verify |
| **P2** | **숏 영상 — Runway** 중심 생성 파이프 (조직 키·서버 어댑터·잡/링크 반영) | 사용자 1차 의도: “쇼츠를 Runway로” |
| **P3** | **음악 — 완성곡 + 가사** 우선, 이후 배경/스템 | API·약관·큐 설계 병행 |
| **P4** | **TTS 말하기** | 노래/멜로디 보컬은 장기 |
| **P5** | **유튜브 업로드·메타** 자동화 | OAuth/쿼터·정책 — P0 키 관리 위에 단계적 |
| **P6** | **성과 지표** — 조회·좋아요·댓글·바이럴/수익 신호 | YouTube Data/Analytics 범위·RLS·개인정보 |

**통합 제공자 후보 (Claude 외 최대 10 — 우선순위·약관 별도 검토):**

1. **Runway** — 숏 영상 생성 (사용자 명시)
2. **ElevenLabs** — 말하기 TTS (대중적)
3. **OpenAI TTS** — 이미 OpenAI 키가 있을 때 음성 레이어 통합 용이
4. **Google Cloud Text-to-Speech** — GCP 키와 묶는 조직에 적합
5. **Suno / Udio** — 완성곡+가사(제품별 API·약관 상이 — BUILD 전 검증)
6. **YouTube Data API v3** — 이미 스키마 후보; 메타·일부 분석
7. **YouTube Analytics / Reporting** — 조회·좋아요·댓글 집계(스코프·OAuth 난이도 높음)
8. **Mubert / 유사** — 스템·배경만 필요 시 P3 보조
9. **AssemblyAI / Deepgram** — 자막·검수 파이프(선택)
10. **Amazon Polly / Azure Neural TTS** — 엔터프라이즈 TTS 대안

*실제 BUILD에는 “한 스프린트에 1~2 제공자”만 — 아래 비목표와 함께 스코프 캡.*

## 3. 비목표 (이번 PLAN에서 명시적으로 닫는 것)

| 항목 | 이유 |
|------|------|
| **버추얼 캐릭터·립싱크 1차 축** | 인터뷰상 1차 손대지 않음; 쇼츠는 Runway 우선 |

| **배경·스템만 먼저** | 완성곡+가사가 먼저 |
| **고정 “N주” 일정** | 스프린트 단위 연속 배포; 주차 숫자는 계획의 SoT가 아님 |

**열어둠 (장기):** OAuth·제공자별 확장, 음악/보컬/TTS 고도화, 수익·바이럴 대시보드.

## 6. 다음 PLAN 단계 (실행 순서 — 주차 고정 없음)

1. **CREATIVE (얇게):** P0~P2만 **한 페이지 다이어그램** — 데이터: 에피소드 → 아티팩트 → 외부 잡 링크 / 키는 Integrations.
2. **BUILD 스프린트 1:** Claude `provider` + 마이그레이션 + verify + 탭 (기존 패턴 복제).
3. **BUILD 스프린트 2:** Runway 어댑터 스텁(health + job 생성·폴링 최소) + 아티팩트 반영 필드 합의.
4. **PLAN 스파이크:** 완성곡+가사 — Suno/Udio 등 **API 가능성·약관** 1~2일 조사 → 채택/보류 결정.
5. **BUILD 이후:** TTS(말하기) 1종 · 유튜브 업로드/메타는 OAuth 설계와 함께 분리 이슈.

**원칙:** 매 스프린트는 `pnpm verify` 통과·플래그 기본 꺼짐 유지; North Star 문서와 충돌 시 [`tasks.md`](../../memory-bank/tasks.md)에서 조정.
