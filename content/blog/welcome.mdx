This is the minimal **MDX** pipeline: posts live in `content/blog/*.mdx` next to the app code. Build time reads front matter and renders on `/blog` and `/blog/[slug]`.

## What you will see here

- Release notes and roadmap context for Prompt Studio and Library
- Practical prompts and MICE-adjacent workflow notes
- Occasional deep dives when they help our users

## Contributing

Add a new `your-slug.mdx` file with YAML front matter (`title`, `description`, `date`). Optional `locale` limits a post to one locale (e.g. `ko`).
