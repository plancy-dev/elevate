# Example ebook (in-app reader)

This MDX file is loaded from `content/ebooks/example-ebook/index.mdx` when a catalog row uses `slug = example-ebook`, `delivery_mode = web_only`, and the user passes Library access checks.

Set **`delivery_mode`** to `web_only` in Supabase for this SKU to show **Read online** in the dashboard Library.
